# Report pages

## İcmal

The overview provides signed sales, positive sales and returns, average receipt value, distinct products, receipt counts, a daily sales trend and the four highest-selling categories. Transaction-type filters distinguish sales and returns in the relevant cards.

## Satış Ritmi

A weekday-by-hour matrix shows sales patterns. Column charts compare hourly sales and weekdays. Date and department filters support analysis within the current selection.

## Səbət və Kartlar

The page compares card and non-card receipt counts, average receipt values and sales shares. A bar chart shows receipt-value band counts, and a receipt-type slicer filters the distribution.

## Qaytarmalar

Cards show absolute return amount, the return ratio, return row count and return receipt count. A daily chart displays return amounts. Tables display the five categories with the largest return amounts and the three products with the largest return amounts. The category ratio follows the saved DAX definition documented in metrics.md.

The source package reflects all four submitted report pages. It does not present the earlier conceptual design images as screenshots of the final Power BI report.
